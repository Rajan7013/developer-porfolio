# Brand font

`brand.woff2` is a subset of Clicker Script containing the letters used by the `Rajan` wordmark. The original font is by Brian J. Bonislawsky and Jim Lyles (Astigmatic), licensed under SIL OFL 1.1; see `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/clickerscript

Subset created with FontTools (`pyftsubset original.woff2 --text=Rajan --flavor=woff2 --output-file=brand.woff2`). Keep the license with the font. If the wordmark changes, regenerate the subset with its new letters.
